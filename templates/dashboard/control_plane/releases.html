Подготовить новый релиз

Сначала сервер проверит ZIP и построит manifest. Подпись выполняется отдельным следующим шагом на вашем ПК.

1
ZIP-пакет на сервереИменно этот файл будет скачивать Workspace Organizer.
2
Версия и каналUpdater использует version_code для сравнения релизов, а channel — для выбора ленты.
3
Источник и совместимостьЭти поля входят в подписанный manifest.

Процесс публикации

  1. ZIP на сервереControl plane проверяет файл и считает SHA-256.
  2. ManifestСтроится автоматически из полей этой формы.
  3. Локальная подписьUpdate private key читается только helper на вашем ПК/флешке.
  4. Серверная проверкаГотовая wou1 signature повторно проверяется public trust root.
  5. FeedПосле проверки релиз появляется в выбранном канале.

Если local signer недоступен, exact manifest можно подписать полностью офлайн и импортировать через «Расширенный импорт».
