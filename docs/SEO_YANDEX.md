# Индексация JSInteractive в Яндекс

## Подтверждение прав

Основной способ подтверждения — метатег в `<head>` главной страницы:

```html
<meta name="yandex-verification" content="725d05a47d08b13d">
```

Значение задаётся переменной `YANDEX_WEBMASTER_VERIFICATION`. Даже если в настройках сайта поле подтверждения случайно сохранено пустым, публичный шаблон использует системное значение как резервное.

## Что публикует сайт

- `/robots.txt` — разрешает публичные страницы, закрывает служебные маршруты и содержит ссылку на Sitemap.
- `/sitemap.xml` — главная и все опубликованные статьи, до 50 000 URL, с `lastmod`.
- `/<YANDEX_INDEXNOW_KEY>.txt` — корневой ключ IndexNow.
- публичные HTML-страницы содержат canonical, robots, title и description;
- статьи содержат Schema.org `BlogPosting` и `BreadcrumbList`;
- проекты содержат `SoftwareApplication` и `BreadcrumbList`;
- главная содержит `ProfilePage` автора и `ItemList` проектов;
- служебные страницы, `/contact` и демонстрационная форма `/demo/vanga` получают `X-Robots-Tag: noindex, nofollow`;
- `/demo/vanga` имеет canonical на индексируемую страницу `/projects/vanga` и не включается в Sitemap.

`/contact` намеренно не закрывается через `robots.txt`: поисковый робот должен иметь возможность увидеть директиву `noindex`.

## IndexNow

В production IndexNow включён по умолчанию:

```env
YANDEX_INDEXNOW_ENABLED=true
YANDEX_INDEXNOW_KEY=jsinteractive-indexnow-725d05a47d08b13d
```

При публикации, изменении URL, снятии с публикации или удалении статьи приложение ставит в очередь старые и новые публичные URL. Изменение главной страницы также отправляет её адрес.

Для первичной повторной отправки уже существующего контента после выкладки:

```bash
.venv/bin/python tools/reindex_yandex.py
```

HTTP 200 означает, что запрос принят. HTTP 202 допустим для нового ключа: Яндекс ещё проверяет файл ключа.

## Действия в Яндекс Вебмастере после выкладки

1. Добавить или открыть `https://jsinteractive.ru/` и подтвердить права по метатегу.
2. В «Индексирование → Файлы Sitemap» добавить `https://jsinteractive.ru/sitemap.xml`.
3. Запустить приоритетный переобход Sitemap.
4. В «Индексирование → Переобход страниц» отправить главную и наиболее важные статьи.
5. Привязать счётчик Метрики к сайту и включить «Обход по счётчикам».
6. В инструментах Вебмастера проверить:
   - анализ `robots.txt`;
   - валидатор Sitemap;
   - проверку ответа сервера для главной и статьи;
   - валидатор микроразметки;
   - отсутствие неожиданных страниц в разделе «Страницы в поиске».

IndexNow, Sitemap и ручной переобход ускоряют обнаружение страниц, но не гарантируют их включение в поиск: окончательное решение принимает поисковая система.
