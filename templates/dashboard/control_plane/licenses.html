Выпустить новую лицензию

Параметры задаются на сайте, но Ed25519-подпись выполняется локально на вашем компьютере.

Установка и клиентInstallation ID копируется с той установки Workspace Organizer, для которой выпускается лицензия.

Параметры лицензииЭти значения входят в подписанный wo1 token и не меняются без нового выпуска.

3
Доступ к обновлениямЭто серверные ограничения control plane; они не изменяют сам локальный license token.
4
Ключи на этом компьютереВставьте флешку или укажите локальную папку. Web-сервер этот путь не получает.
Запустите local signer на этом компьютере, вставьте код подключения и выберите папку с ключами системным диалогом.
Как запустить local signer

На компьютере, где физически находится флешка/папка с private keys, запустите tools/operator-signer/start.ps1 (Windows) или tools/operator-signer/start.sh (Linux/macOS). Он слушает только 127.0.0.1 и показывает временный код подключения.

Что происходит при выпуске

  1. Проверяем папкуLocal signer ищет Workspace Organizer keys и возвращает только public fingerprint.
  2. Сверяем trust rootPrivate key должен соответствовать production public key, который знает сайт.
  3. Подписываем локальноPrivate key остаётся на вашем ПК/флешке.
  4. Регистрируем wo1 tokenНа сервер отправляется только уже подписанная лицензия.
  5. Выдаём activation codeОтдельный одноразовый код для online updater.

Браузер сам не имеет права читать D:\ или флешку. Доступ к ОС выполняет только локальный helper на 127.0.0.1.
