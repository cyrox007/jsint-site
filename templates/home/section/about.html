О студии

Интерактивная инженерия

Разрабатываю системы для быстрой обработки данных и обмена информацией в реальном времени, включая онлайн-банкинг и интернет-магазины. Использую WebSocket и API для создания серверных и веб-приложений.

Независимый открытый исходный код

Большая часть проектов развивается как независимые open-source платформы. Особенно интересуют системы, которые пользователь может контролировать сам.
