# Бренд Workspace Organizer

## Название

Публичное название продукта: **Workspace Organizer**.

`Notes` — рабочее имя репозитория и историческое внутреннее обозначение. Оно не используется как публичный бренд, публичный URL, canonical name или alternateName в SEO-разметке.

## Публичный URL

Основная продуктовая страница:

```text
/workspace-organizer
```

Старый `/notes` существует только как постоянный HTTP 301 redirect для уже опубликованных ссылок.

Айдентика основана на выбранном бренд-референсе:

| Роль | Цвет |

```text

```

## Визуальный язык

- светлые бело-голубые поверхности;
- глубокий navy для контраста и security/self-hosted блоков;
- объёмные, но не «игрушечные» голубые градиенты;
- цвет модулей используется точечно: задачи — зелёный, файлы — оранжевый, команда — фиолетовый, безопасность — cyan;
- большие скругления допустимы для промо и app icon, но рабочий UI остаётся компактнее;
- не использовать emoji как продуктовые иконки;
- знак Workspace Organizer — многослойное рабочее пространство/папка, а не блокнот.

## Ассеты

- `static/public/workspace-organizer-mark.svg` — самостоятельный знак;
- `static/public/workspace-organizer-logo.svg` — знак + название продукта.

SVG используется как основной web-формат: он масштабируется без потери качества и сохраняет фирменную палитру независимо от DPR экрана.

## Кнопки и spacing

Публичные CTA используют единый базовый ритм:

- высота не меньше 50 px;
- горизонтальный padding 22 px;
- вертикальный padding 12 px;
- gap между иконкой и текстом 10 px.

В админке:

- базовая кнопка — минимум 42 px;
- padding 10 × 16 px;
- compact button — минимум 34 px;
- соседние action-кнопки разделяются минимум 8–12 px.

Карточки и независимые панели не должны визуально «склеиваться»: рабочий межблочный ритм 14–20 px в зависимости от плотности экрана.
